# 🌙 LUNAR HUB | Standoff 2

**LUNAR HUB** — это модифицированный клиент для игры **Standoff 2** с расширенными возможностями.  
Проект создаётся для удобства и разнообразия игрового процесса.

---

## 🔥 Возможности (в разработке)
- ✅ **Aimbot** — автоматическое наведение на цель.
- ✅ **Wallhack** — просмотр противников через стены.
- ✅ **Авто-прицел** — мгновенная реакция на врага.
- ✅ **Смена скинов оружия** (локально).
- ✅ **Безопасный режим** — защита от обнаружения (в планах).
